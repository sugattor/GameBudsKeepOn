# GameBudsKeepOn

Arctis GameBuds の自動電源オフを「なし」に戻す道具。
実行は 1 回だけ。常駐しない。
これは SteelSeries の公式の道具ではない。

## 1. この道具について

### 何をするか

| 項目 | 内容 |
|---|---|
| 症状 | SteelSeries GG で「なし」に保存しても、イヤホンが切れる場合がある |
| この道具の仕事 | 自動電源オフの値だけを書き換える |
| 実行する場面 | イヤホンをケースから出したあと |
| 実行の回数 | 1 回。自動起動はしない |

メーカーの既定は 30 分。最初にこの道具で「なし」にすると、GG を閉じている間はその値が保たれる。GG が動いていると、ケースから出すたびに値が戻る場合がある。

同じ症状の報告:

| 出典 | 内容 |
|---|---|
| [Reddit 2025-01](https://www.reddit.com/r/steelseries/comments/1i21r77/arctis_gamebuds_turning_off_automatically_if_no/) | 無音で 10 分で切れる。保存しても翌日には戻る |
| [Reddit 2025-04](https://www.reddit.com/r/steelseries/comments/1k0n80t/arctis_gamebuds_always_turning_off/) | 両方のアプリで「なし」でも切れる |

### 必要なもの

| 項目 | 内容 |
|---|---|
| 対応端末 | SteelSeries Arctis GameBuds と USB-C の 2.4GHz ドングル |
| パソコン側 | PowerShell 7 |
| SteelSeries GG | 無くても動く。動いているときは GG の設定も合わせて直す |
| 接続 | USB-C のドングル。Bluetooth では動かない |
| 管理者権限 | 不要 |
| PC の再起動 | 不要 |

### 動作の概要

| 場面 | 動作 |
|---|---|
| GG が動いている | GG の設定も同じ値へ直す |
| GG が動いていない | USB 経由で本体へ直接書く |

## 2. 使い方

PowerShell 7 を開き、この README のある場所へ移動して、次を実行する。

```
.\GameBudsKeepOn.ps1
```

実行すると、接続を確認し、現在の値を読み、目標と違えば書き換え、結果を表示して終わる。

画面に出る行の例:

```
POLL 経路=Hid 接続=はい 現在=0 目標=0 書いた=いいえ
```

| 項目 | 意味 |
|---|---|
| `経路` | 使った経路。`Hid` は USB 経由。`Engine` は GG 経由 |
| `接続` | イヤホンが取り出されていて、本体から返事があったか |
| `現在` | 実行時点の自動電源オフ。0 は「なし」 |
| `目標` | この道具が狙う値 |
| `書いた` | 今回書き換えたか。`はい` なら、もう 1 回実行して `現在` を確かめる |

書き換えたかどうかは、もう 1 回実行して分かる。同じ実行の中では本体を 2 回読めないため。

### 引数

| 引数 | 効果 |
|---|---|
| なし | 目標を「なし」(0) にして実行する |
| `-Minutes 30` | 目標を 30 分にする |
| `-DryRun` | 値を読むだけ。書き込まない |
| `-Channel Hid` | USB 経由だけを使う |
| `-Channel Engine` | GG 経由だけを使う |
| `-Force` | 値が同じでも書き込む |

例:

```
.\GameBudsKeepOn.ps1 -Minutes 30
.\GameBudsKeepOn.ps1 -DryRun
```

## 3. 設定できる値

| 値 | 意味 |
|---|---|
| 0 | なし。自動電源オフしない |
| 1 | 1 分 |
| 5 | 5 分 |
| 10 | 10 分。勝手にこの値へ戻るとの報告が多い |
| 15 | 15 分 |
| 30 | 30 分。メーカーの既定 |
| 45 | 45 分 |
| 60 | 60 分 |
| 75 | 75 分 |
| 90 | 90 分 |

この道具の既定は 0（なし）。GG の画面で選べるのは上の 10 個だけ。この道具は 0 から 1440 まで受け付ける。画面に無い値を入れると警告が出る。

## 4. ログの場所

| ファイル | 内容 |
|---|---|
| `%LOCALAPPDATA%\GameBudsKeepOn\log.txt` | 実行の記録 |
| `%LOCALAPPDATA%\GameBudsKeepOn\state.txt` | 直前の状態。変わったときだけ記録 |

主な行:

| 行 | 意味 |
|---|---|
| `状態=未接続 ドングルを認識していない` | GG からドングルが見えない |
| `状態=ドングル無し USB に見えない` | ドングルが刺さっていない |
| `状態=済み 自動電源オフ=<値> 電池=<値>` | 目標どおり |
| `状態=書き込み 自動電源オフ=<値> (前は <値>) 電池=<値>` | 書き換えた |
| `状態=成功 自動電源オフ=<値>` | GG 経由で書き換えて、読み直しも一致 |
| `状態=試行 自動電源オフ=<値> 目標=<値>` | `-DryRun`。書き込んでいない |
| `状態=注意 目標=N 分は GG の画面の候補に無い値` | 画面に無い値を指定した |
| `状態=失敗 ...` | 経路ごとの失敗理由 |

## 5. 困ったとき

| 状況 | 対処 |
|---|---|
| GG が動いているのに値が戻る | 取り出したあとに実行する。戻ったらもう 1 回実行して `現在=0` を確かめる |
| 初めて使う | まず 1 回実行して「なし」にする。メーカーの既定は 30 分 |
| ケースに入っている | 書き込まない。出してから実行する |
| ドングルが見えない | USB に刺し直して、もう 1 回実行する |
| GG の画面と違う | GG の画面は手元のコピー。`-DryRun` で本体の値を確かめる |
| GG が無い | そのまま実行できる。`-Channel Hid` も使える |

## 6. 元の設定へ戻す

メーカーの既定は 30 分。

```
.\GameBudsKeepOn.ps1 -Minutes 30
```

GG の画面から変更してもよい。
